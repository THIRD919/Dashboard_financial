# Excel Import User Flow

1. Upload `.xlsx` locally.
2. Validate file structure and choose/detect an active profile.
3. Map period labels, Units, metrics, categories, scope and budget scope to configured masters.
4. Review row-level errors, warnings, duplicates and source cells.
5. Review financial totals and Faculty-versus-Unit reconciliation.
6. Confirm only when no blocking errors remain.
7. Commit every eligible row in one transaction and show the result in Import History.

Cancellation before confirmation writes no financial records. Exact duplicates are shown and skipped. Conflicts block confirmation; the user must correct the workbook or use a later approved adjustment workflow.
