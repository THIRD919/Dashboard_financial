# Final Approver Guide

Open **Final Approval**. Review the submission, reviewer identity/comment, financial summary, and source. Choose **Final Approve** or return it with a required reason. Final approval does not yet make data official: confirm **Lock** separately after reading the warning.

For locked data, use **Request Correction**, select Adjustment or Reversal, and state the reason. The request is assigned to the original Data Entry user; the original is retained.
