# Phase 5A Permission Matrix

| Role | Capabilities |
|---|---|
| VIEWER | dashboard.view, financial.view |
| EXECUTIVE | dashboard.view, financial.view, reconciliation.view |
| DATA_ENTRY | dashboard.view, financial.view, financial.create, financial.update, financial.update_draft, financial.submit, financial.delete_draft |
| ADMIN | All Phase 5A dashboard, financial-entry, import, reconciliation, users, roles, units, KPI, audit, system and Faculty-scope capabilities |

ADMIN does not receive Phase 5B approval, reject, lock, unlock, adjust, or reverse capabilities.
