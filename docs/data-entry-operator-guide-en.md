# Data Entry Operator Guide (English)

Open `/en/data-entry`, select a development user context, and choose an authorized scope, reporting period, and unit. Enter at least one actual or budget value and provide a source reference.

- Blank means “No data”; it does not mean zero.
- Enter `0` when the authoritative reported value is zero.
- Mark budget scope as Annual, Period, or Scope Not Confirmed.
- Review the automatically calculated indicators before saving.
- **Save Draft** keeps the batch editable/deletable through the draft services.
- **Submit** opens a confirmation review. Submitted records cannot be edited directly.
- If a duplicate is reported, inspect the existing record; the system does not overwrite it.

Submitted values can appear in the development dashboard projection as `SUBMITTED_PREVIEW`; they are not treated as approved accounting data.
