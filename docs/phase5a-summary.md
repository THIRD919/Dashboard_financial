# Phase 5A Summary

Phase 5A adds provider-portable authentication, ACTIVE/INACTIVE/SUSPENDED profiles, roles, capabilities, many-to-many Unit access, protected routes/actions, PostgreSQL RLS policies, an Admin console, and administrative audit events. Thai is the default and English is supported. The local provider is TEST_ONLY and cannot activate in a production build. Supabase Auth remains the real provider boundary.

Not included: approval decisions, period locking, corrections/reversals, CMU SSO, deployment, or Phase 5C hardening.
