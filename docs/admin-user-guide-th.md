# คู่มือผู้ดูแลระบบ

เข้าสู่ระบบที่ `/th/login` แล้วเปิดเมนูผู้ดูแลระบบ ใช้แท็บผู้ใช้งานเพื่อค้นหา เพิ่ม/เชิญ แก้ไขภาษา และเปลี่ยนสถานะ ใช้ “สิทธิ์ตามหน่วยงาน” เพื่อกำหนดบทบาทและสิทธิ์ READ/WRITE การเลือก All Units — Read ไม่ให้สิทธิ์เขียนอัตโนมัติ ระบบไม่อนุญาตให้ปิดผู้ดูแลระบบคนสุดท้าย ตรวจสอบผลที่แท็บประวัติการใช้งาน
