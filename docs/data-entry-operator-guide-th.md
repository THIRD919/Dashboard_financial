# คู่มือผู้บันทึกข้อมูล (ภาษาไทย)

เปิด `/th/data-entry` แล้วเลือกบริบทผู้ใช้สำหรับการพัฒนา เลือกขอบเขต ปี รอบรายงาน และหน่วยงานที่ได้รับสิทธิ์ จากนั้นกรอกค่าจริงหรืองบประมาณอย่างน้อยหนึ่งรายการ พร้อมเอกสาร/แหล่งอ้างอิง

- ช่องว่างหมายถึง “ไม่มีข้อมูล” ไม่ใช่ศูนย์
- หากค่าที่รายงานเป็นศูนย์จริง ให้กรอก `0`
- ระบุขอบเขตงบประมาณเป็นทั้งปี รายงวด หรือยังไม่ยืนยัน
- ตรวจสอบค่าคำนวณอัตโนมัติก่อนบันทึก
- **บันทึกฉบับร่าง** ยังลบหรือแก้ไขผ่านบริการได้
- **ส่งข้อมูล** ต้องตรวจสอบในหน้าต่างยืนยัน และหลังส่งแล้วแก้ไขโดยตรงไม่ได้
- หากระบบแจ้งข้อมูลซ้ำ ให้ตรวจสอบรายการเดิม ระบบจะไม่เขียนทับ

ค่าที่ส่งแล้วจะแสดงในมุมมองแดชบอร์ดสำหรับการพัฒนา แต่ยังคงสถานะ `SUBMITTED_PREVIEW` จนกว่าจะมีกระบวนการอนุมัติในระยะถัดไป
