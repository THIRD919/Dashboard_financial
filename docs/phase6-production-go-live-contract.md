# Phase 6 Production Go-Live Contract

Phase 6 requires explicit stakeholder approval and may only: provision approved infrastructure; finish staging acceptance; configure production authentication/SSO; deploy the verified application/migrations/master bootstrap; activate production backup/monitoring; run final smoke, security and financial UAT; execute the approved go-live/rollback decision.

It may not invent SSO details/domains, reuse staging secrets, seed test users/facts, enable Demo Auth, bypass unresolved go-live gates, or mutate official history. Production deployment has not occurred in Phase 5C.
