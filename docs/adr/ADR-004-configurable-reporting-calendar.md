# ADR-004: Configurable Reporting Calendar

- Status: Accepted
- Decision: Store source fiscal-year/quarter labels, optional month, start/end dates, display order and active/locked state; do not hard-code mappings.
- Rationale: Excel does not prove Thai fiscal, calendar or other convention.
- Consequences: Dates may remain null pending approval. Imported labels are preserved and administration can configure periods without code change.
