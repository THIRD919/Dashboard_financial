# User Management

The bilingual Admin Console supports search, secure invite/create, profile language/status, roles, multiple Unit grants, Unit names/order/status, and audit history. Provider IDs are hidden. System roles are protected, and the final active Admin cannot be deactivated or lose ADMIN. Prefer INACTIVE/SUSPENDED and grant revocation over deletion. Audit data includes actor, target, old/new values, timestamp, and event code without secrets.
