# คู่มือ UAT ระยะ 5B

รัน `npm run demo:auth` และใช้รหัสผ่าน `VetCmu-Test-Only-2569` กับบัญชีทดสอบ:

- `office.reviewer.test@local` — ผู้ตรวจสอบสำนักงาน
- `secretary.reviewer.test@local` — เลขานุการคณะ
- `vicedean.approver.test@local` — ผู้อนุมัติขั้นสุดท้าย

กรณีหลัก: ส่งข้อมูลสำนักงาน Q2/69 รายรับ 1,000,000 รายจ่าย 700,000 สินทรัพย์หมุนเวียน 500,000 หนี้สิน 250,000 ให้ผู้ตรวจสอบอนุมัติ จากนั้นรองคณบดีอนุมัติขั้นสุดท้ายและปิดงวด ตรวจผลทางการ 300,000 อัตรากำไร 30% และสภาพคล่อง 2.00 เท่า ขอปรับรายจ่าย +20,000 แล้วอนุมัติและปิดงวด ตรวจรายจ่าย 720,000 ผล 280,000 และอัตรากำไร 28% ทดสอบกลับรายการ 100,000 ด้วย −100,000 ให้ยอดสุทธิเป็นศูนย์

กรณีปฏิเสธ: ผู้ส่งห้ามตรวจเอง ผู้ตรวจสอบและ ADMIN ห้ามอนุมัติขั้นสุดท้าย ผู้ตรวจสอบต่างหน่วยงานถูกปฏิเสธ และข้อมูลปิดงวดห้ามแก้ ลบ บันทึกปกติ หรือนำเข้าซ้ำในขอบเขตนั้น
