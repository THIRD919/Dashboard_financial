# คู่มือผู้อนุมัติขั้นสุดท้าย

เปิดเมนู **อนุมัติขั้นสุดท้าย** ตรวจรายการ ผู้ตรวจสอบ ความเห็น สรุปการเงิน และแหล่งข้อมูล จากนั้นเลือก **อนุมัติขั้นสุดท้าย** หรือส่งกลับโดยระบุเหตุผล การอนุมัติยังไม่ทำให้ข้อมูลเป็นทางการ ต้องยืนยัน **ปิดงวด** แยกต่างหากหลังอ่านข้อความเตือน

หากต้องแก้ข้อมูลที่ปิดงวดแล้ว ให้กด **ขอแก้ไขข้อมูล** เลือกรายการปรับปรุงหรือกลับรายการ และระบุเหตุผล ระบบมอบหมายให้ผู้บันทึกเดิมและเก็บรายการเดิมไว้เสมอ
