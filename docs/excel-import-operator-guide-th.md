# คู่มือผู้ปฏิบัติงานนำเข้า Excel

1. เริ่มระบบด้วย `npm run demo` และเปิด `http://localhost:3000/th/import`
2. ใช้ไฟล์ `templates/TEST_ONLY_Vet_CMU_Office_Q2_69.xlsx` สำหรับการทดสอบครั้งแรก
3. เลือกไฟล์ แล้วกด **อัปโหลดและตรวจสอบ**
4. ตรวจสอบจำนวนรายการ การจับคู่ เซลล์ต้นทาง คำเตือน ข้อผิดพลาด และข้อมูลซ้ำ
5. ตรวจสอบสรุปทางการเงินและการกระทบยอด
6. ปุ่ม **ยืนยันการนำเข้าข้อมูล** จะใช้งานได้เมื่อไม่มีข้อผิดพลาดที่ปิดกั้น
7. หลังนำเข้าสำเร็จ เปิด Dashboard เลือกสำนักงาน คณะสัตวแพทยศาสตร์ และตรวจสอบยอด

ข้อควรจำ: ช่องว่างหมายถึงไม่มีข้อมูล; เลขศูนย์หมายถึงค่าจริงเป็นศูนย์ ห้ามแก้ปัญหาข้อมูลเดิมด้วยการเขียนทับ และห้ามนำไฟล์ลับออกนอกเครื่องใน Phase 4C
