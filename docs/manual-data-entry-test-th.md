# คู่มือทดสอบการบันทึกข้อมูลด้วยตนเอง

1. เปิด Terminal
2. เข้าโฟลเดอร์โครงการ:

   ```bash
   cd /Users/ninu/Desktop/Project_codex/Dashboard_financial
   ```

3. เริ่มระบบทดสอบ:

   ```bash
   npm run demo
   ```

   ระบบต้องแสดง URL `http://localhost:3000` หากแจ้งว่า port 3000 ถูกใช้งาน ให้หยุด Terminal เดิมที่กำลังรัน Dashboard ก่อน แล้วรันคำสั่งนี้ใหม่ ระบบจะไม่สลับไปใช้ port อื่นโดยอัตโนมัติ

4. เปิด `http://localhost:3000/th/data-entry`
5. เลือกผู้ใช้งาน **เจ้าหน้าที่สำนักงาน**
6. ตรวจสอบหน่วยงาน **สำนักงาน คณะสัตวแพทยศาสตร์** และรอบ **Q2/69**
7. กรอก:

   - รายรับ ผลจริง: `1000000`
   - รายจ่าย ผลจริง: `700000`
   - สินทรัพย์หมุนเวียน: `500000`
   - หนี้สิน: `250000`

8. กด **คำนวณอัตโนมัติ** ควรได้ผลการดำเนินงาน `300,000.00`, อัตรา `30.0%`, และสภาพคล่อง `2.00 เท่า`
9. กด **บันทึกฉบับร่าง** แล้วรีเฟรชหน้า รายการฉบับร่างต้องยังอยู่
10. กดไอคอน **เปิดฉบับร่าง** ในตาราง กด **ส่งข้อมูล** แล้วกด **ยืนยันการส่ง**
11. ตรวจสอบว่าสถานะเป็น **ส่งข้อมูลแล้ว** และแก้ไขโดยตรงไม่ได้
12. เปิด `http://localhost:3000/th/dashboard` เลือกหน่วยงาน **สำนักงาน คณะสัตวแพทยศาสตร์** แล้วตรวจสอบรายรับ 1M รายจ่าย 700K ผลการดำเนินงาน 300K อัตรา 30.0% และสภาพคล่อง 2.00 เท่า

เมื่อต้องการเริ่มทดสอบใหม่ ให้หยุดระบบแล้วรัน:

```bash
npm run demo:reset
```

ข้อมูลทั้งหมดเป็น `TEST_ONLY` และอยู่ในฐานข้อมูลท้องถิ่นเท่านั้น
