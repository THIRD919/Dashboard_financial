# คู่มือผู้ตรวจสอบ

เข้าสู่ระบบด้วยบัญชี REVIEWER และเปิดเมนู **ตรวจสอบ** ผู้ตรวจสอบสำนักงานจะเห็นเฉพาะหน่วยงานที่ได้รับสิทธิ์ ส่วนเลขานุการคณะเห็นทุกหน่วยงาน

1. กด **เริ่มตรวจสอบ**
2. ตรวจรายรับ รายจ่าย ผลการดำเนินงาน อัตรากำไร สภาพคล่อง แหล่งข้อมูล งวด หน่วยงาน และผู้ส่ง
3. กด **ผ่านการตรวจสอบ** พร้อมความเห็น (ถ้ามี) หรือ **ส่งกลับเพื่อแก้ไข** โดยระบุเหตุผล

ผู้ตรวจสอบห้ามตรวจรายการของตนเอง อนุมัติขั้นสุดท้าย หรือปิดงวด
